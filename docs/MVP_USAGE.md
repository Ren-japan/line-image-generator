# LINE Image Generator MVP - 使い方ガイド

## 初回セットアップ手順（5分）

### Step 1: サイト/案件を登録

1. 左サイドバー → 「⚙️ サイト設定」
2. 新規サイト作成。サイト名は例えば：
   - `medical-diet-koizumi`（医療ダイエット × こいずみ）
   - `aga-oda`（AGA × ODAクリニック）
   - `nursing-leval`（看護師 × レヴァエル）
3. ブランドカラーを設定：
   - **primary_color**: メインのテーマカラー（例: 医療ダイエットなら #1A8FFF）
   - **accent_color**: アクセントカラー（CTAボタンなどに使われる赤系・橙系）

### Step 2: ロールモデル画像をアップロード

Driveの該当ジャンル/案件フォルダから過去のヒット作をDL → サイト設定のリファレンス画像登録：

#### PUバナー用
- カテゴリ: `pu`（手入力可なら）
- 推奨枚数: 3〜5枚
- ロールモデル例: `04_LINE施策/{ジャンル}/_02_MS/{案件}/離脱PU/` 等

#### カルーセル用
- カテゴリ: `carousel`
- 推奨枚数: 3〜5枚（**全枚で同じテイストになる**ので慎重に選ぶ）
- ロールモデル例: `04_LINE施策/{ジャンル}/_02_MS/{案件}/{診断名}/設問パネル/` 等

> カテゴリ機能がUIに無ければ、通常の参照画像として登録すればOK。LINE版が自動でフォールバックして使う。

### Step 3: PUを生成してみる

1. メインメニュー → 「📣 PU画像生成」
2. **訴求テーマ**: 例「隠れ肥満度チェック」
3. **ターゲット**: 例「30代女性、最近お腹周りが気になる」
4. 「AIで文言案を生成」をクリック → 3案ほど出る
5. 案を選択（複数可）
6. サイズ確認（デフォルト1080×1080） → 「選択した案を一括生成」
7. 結果表示 → 気に入らなければ「微修正」、良ければPNG DL

### Step 4: カルーセルを生成してみる

1. メインメニュー → 「🎠 カルーセル生成」
2. **診断テーマ**: 例「隠れ肥満度チェック」
3. **総スライド枚数**: スライダーで3〜10枚（デフォルト6）
4. 「AIで文言を設計」 → 表紙+設問N+結果のJSONが生成される
5. 各スライドの文言を確認・編集
6. サイズ確認（デフォルト1080×1080） → 「全N枚を一括生成」
7. プログレスバー進行、全枚生成 → ZIPダウンロード

## 確認チェックリスト

最初の動作確認で以下を順に試す：

- [ ] サイドバーで「Gemini Key: 設定済み」「OpenAI Key: 設定済み」が両方表示
- [ ] サイト/案件のドロップダウンが選択可能
- [ ] サイト登録時に「✅ サイトを作成しました」が出る
- [ ] PU文言案がGeminiから返ってくる（数秒）
- [ ] PU画像が生成される（OpenAI gpt-image-2、~10秒）
- [ ] カルーセル文言設計がGeminiから返ってくる（数秒）
- [ ] カルーセル全N枚が生成される（1枚10秒×N）

## エラー時の典型対応

| エラー | 原因 | 対応 |
|---|---|---|
| `OPENAI_API_KEY が未設定` | Secrets未反映 | Streamlit Cloud再起動 |
| `billing_hard_limit_reached` | OpenAIキー側の上限 | Billing dashboardで確認 |
| 画像が真っ白で生成される | プロンプト過長 | 文言を短く・参照画像追加 |
| JSON解析エラー | Geminiレスポンス崩れ | テーマを変えて再試行 |

## 既知の制約（MVPレベル）

- カルーセルの統一トーンは「同じ参照画像」を全枚に渡すことで担保（精度は参照画像の質次第）
- PU画像は1080×1080デフォルト（LINE WebView の比率に合わせて変更可）
- Google Drive保存機能は使ってない（ローカルストレージのみ）
